# 🌍 Exponect

**Exponect** is a React Native mobile application that connects **Ethiopian exporters** with **international importers**, providing a seamless platform for product discovery, communication, and trade facilitation.

## 📱 Features

- 🔎 Browse a curated catalog of Ethiopian export products
- 🧑‍💼 Exporter and Importer profiles
- 💬 In-app messaging and connection requests
- 📦 Product listings with media, descriptions, and pricing
- 🌐 Multilingual support (English & Amharic)
- 🔒 Secure authentication and user management

## 🚀 Tech Stack

- **React Native** (TypeScript)
- **Expo** (for fast development & testing)
- **MongoDB** (database)
- **Express.js** (backend API)
- **Firebase** (optional: for Auth or image storage)
- **React Navigation**
- **Tailwind CSS (via Nativewind)** (for styling)
